Đang kiểm tra CLI trên máy…

Nếu máy chưa có CLI, app sẽ tự cài bằng npm khi bạn bấm Cài đặt hoặc Đăng nhập. Cần có Node.js trên máy.

Khuyến nghị: chọn ChatGPT / Codex → bấm Đăng nhập trên trình duyệt → lưu. API key vẫn dùng được nếu bạn muốn dán khóa thủ công.

Kết nối Zalo Bot

1. Mở Zalo, tìm OA “Zalo Bot Manager”. 2. Chọn Tạo bot. 3. Nhập Bot Token được gửi về. 4. Bấm “Bắt đầu tìm Chat ID”, rồi nhắn một tin mới cho bot trong vòng 25 giây.
