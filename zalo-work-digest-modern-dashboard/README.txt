ZALO WORK DIGEST — MODERN DASHBOARD

Cách chạy:
1. Đặt index.html và dashboard.css cùng một thư mục.
2. Mở index.html trực tiếp bằng trình duyệt.
3. Khi đưa vào dự án hiện tại, bạn có thể đổi tên dashboard.css thành styles.css
   hoặc sửa đường dẫn <link rel="stylesheet" href="dashboard.css">.

Ghi chú:
- Giao diện responsive cho desktop, tablet và điện thoại.
- Có JavaScript nhỏ nằm cuối file HTML để mở menu trên điện thoại và đổi trạng thái menu.
- Các số liệu hiện là dữ liệu mẫu; hãy nối với app.js/backend hiện tại để hiển thị dữ liệu thật.
